# Episode 1 - Inception

 ## CDN - Content Delivery Networks
    network of servers distributed across different locations around the world that delivers files to users from a server geographically closer to them
    1. makes delivery faster 
    2. reduces load on the original server
    
  ##  CDN Link - URL that points to a file hosted on a CDN

  ## Origin - made up of 3 things
    1. protocol - https://
    2. domain - example.com
    3. port - : 443

 ## Same Origin - because protocol,domain, port are same
    https://example.com/page-1
    https://example.com/page-2

## Different origin - cross-origin
    https://example.com
    https://google.com/
